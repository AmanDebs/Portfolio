Software I've shipped

Two systems built end-to-end — one running a real export business day to day, one an AI product with the model output pinned down hard.

In production at Aglo Polymers

Quotation Manager

1:03 walkthrough — a quotation carried through to invoice and packing list. Demo data, not live customer records.

A complete order-to-dispatch document system — Quotation → Order → Proforma Invoice → Commercial Invoice + Packing List — where each document is generated from the previous one, eliminating re-entry and manual arithmetic across the whole chain. It replaced a fully manual spreadsheet-and-retyping process I scoped directly with the client.

Real export-trade rules live in the domain layer: HSN codes, INCO terms, multi-currency (INR/USD/EUR), GST versus zero-rated export treatment, and automatic validation of dispatch quantities against the contractual 10% variance clause. Role-based access with a manager approval gate means unapproved documents export with a "Pending Approval" watermark — the approval state is impossible to bypass. All monetary computation is centralised server-side as a single source of truth.

In daily use by a 5–6 person sales & dispatch team

Resume Roaster

An AI resume-analysis product that scores a resume across 14 categories with supporting evidence quotes, matches ATS keywords against a pasted job posting, produces a prioritised fix list, and rewrites individual bullets in one click with STAR breakdowns.

The interesting part is the guardrails. Every LLM call is constrained by a hand-written JSON Schema and re-validated with Zod, so malformed model output fails loudly instead of quietly rendering a broken dashboard. Scoring arithmetic stays deterministic in TypeScript rather than trusting the model to do maths.

Schema-constrained LLM output — no silent failures
